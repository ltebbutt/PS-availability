More PS5 Console Features

Backwards compatibilityThe PS5® Pro console can play over 8,500 PS4 games. With the PS5® Pro version of the Game Boost feature, you can even enjoy faster and smoother frame rates in some of the PS4 and PS5 console's greatest games.

PS5® Pro Game boostEnjoy faster and smoother frame rates in select PS4 and PS VR games. Turn on the Enhanced Image Quality for PS4 games feature to enable additional system post processing power that can improve the resolution for select PS4 games.

Variable Refresh Rate (VRR)Enhance the visual performance of compatible PS5° games by enabling VRR. This syncs the display's refresh rate to the console's output. Gameplay feels smoother as scenes render seamlessly, graphics look crisper with frame pacing issues and screen tearing minimised.

1440p HDMI Video OutputEnjoy the crisp visual performance of games that natively support 1440p resolution."
